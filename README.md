# Fake News Detection System

## Overview

The Fake News Detection System is a machine learning-based web application designed to classify news content as **REAL** or **FAKE**.

The application provides a simple web interface where users can enter news content and receive a prediction from the trained machine learning model.

## Features

* Fake news detection using Machine Learning
* Simple and user-friendly web interface
* Real/Fake prediction
* Prediction confidence display
* Flask-based backend
* HTML, CSS and JavaScript frontend

## How It Works

1. The user enters news content through the web interface.
2. The frontend sends the news text to the Flask backend.
3. The trained machine learning model processes the text.
4. The model predicts whether the news is **REAL** or **FAKE**.
5. The prediction and confidence are displayed to the user.

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Move into the project directory:

```bash
cd FAKE-NEWS-DETECTION
```

Install the required Python libraries:

```bash
pip install flask pandas numpy scikit-learn joblib
```

## Running the Project

First, train the model:

```bash
python BACKEND/train_model.py
```

Then start the Flask application:

```bash
python BACKEND/app.py
```

Open the local address shown in the terminal in your web browser.
